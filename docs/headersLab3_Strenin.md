# Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

Markdown — это лёгкий язык разметки, который используется для оформления README-файлов, документации, отчётов и даже научных текстов. Он прост в использовании, хорошо читается как в сыром виде, так и после рендеринга, и широко поддерживается GitHub, VS Code и многими платформами.

#### Что такое Markdown?

Markdown — это язык разметки, созданный для максимально простого и удобного написания текстов с минимальным форматированием. Он позволяет быстро создавать структурированные документы.

#### Где применяется Markdown?

- В README-файлах на GitHub
- В системах документирования кода
- В блогах и системах управления контентом
- Для написания технической документации
- В заметках (Obsidian, Notion)

#### Зачем нужен Markdown разработчикам?

Разработчикам Markdown нужен для быстрого написания документации, создания README-файлов, ведения заметок и комментариев. Он экономит время, повышает читабельность и обеспечивает единообразное форматирование текста без использования сложных редакторов.
