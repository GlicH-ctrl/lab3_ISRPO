# Примеры текстового форматирования в Markdown

**Жирный текст** — используется для выделения важных терминов

_Курсив_ — для акцента на определенных словах

**_Жирный курсив_** — для максимального выделения

~~Зачёркнутый текст~~ — для обозначения устаревшей информации

`Встроенный код` — для команд и имен файлов

## Блоки кода

```csharp
Console.WriteLine("Введите первое число: ");
double number1 = Convert.ToDouble(Console.ReadLine());
Console.WriteLine("Введите второе число: ");
double number2 = Convert.ToDouble(Console.ReadLine());
double sum = number1 + number2;
Console.WriteLine($"Результат сложения: {sum}");
```
